### 3.1.3 重投影误差与可视化

将棋盘格三维点 $M_j$ 按 B 的参数投影为 $\hat m_{ij}$，与 A 检测到的角点 $m_{ij}$ 比较。
第 $i$ 张图的误差采用每个角点二维欧氏距离的均方根：

$$
\mathrm{RMS}_i = \sqrt{\frac{1}{n_i}\sum_{j=1}^{n_i}
\left\|m_{ij}-\hat m_{ij}\right\|_2^2}.
$$

整体 RMS 按角点数加权，而非直接对逐图 RMS 求算术平均：

$$
\mathrm{RMS}_{\mathrm{all}} =
\sqrt{\frac{\sum_i n_i\,\mathrm{RMS}_i^2}{\sum_i n_i}}.
$$

本项目同一标定板的成功图像都有相同角点数，因此实现中可取逐图 RMS 平方的均值再开方。
C 从角点、内外参独立重算误差，并与 B 提供的 RMS 对照；出现差异时检查误差定义及图像集合。

### 3.1.4 留一法与内参稳定性

对每台相机的 $N$ 张有效图像，轮流留出一张：

1. 仅用其余 $N-1$ 张重新估计内参和畸变系数，所有折使用相同的 `flags` 和终止条件。
2. 固定这一折的内参和畸变系数，使用留出图的角点通过 `solvePnP` 估计该图的外参。
3. 计算留出图的重投影 RMS，并与同配置下全量 $N$ 张标定的 RMS 对比。
4. 记录该折的 $f_x,f_y,c_x,c_y$，以及焦距相对全量标定结果的变化百分比。

留出图不参与内参标定，但其角点用于拟合该图的姿态，因此这里的验证误差是**拟合姿态后的留出视图重投影误差**。
它能辅助分析视图不足和参数不稳定，不能独立证明真实三维测量精度，也不能据此断言工程采集只需 3～4 张图。

本实现要求每折至少 3 张训练视图，即每台相机至少 4 张有效图像；3 张图的相机可做全量评估，留一折标记为 `insufficient_views`。
视图数量达到要求也不保证姿态充分分散。标定或姿态求解失败时记录 `status/error`，保留其它相机及折的结果，命令返回非零状态。

输出：`outputs/experiments/views_<board>.csv` 和同名 PNG。CSV 记录每折训练/验证 RMS、全量 RMS、内参变化、标定设置和状态。

### 3.1.5 参数合理性与可信度

接入真实结果后逐台相机讨论：

- $f_x,f_y$ 的差异是否符合相机像素和图像缩放方式。
- 主点与图像中心的偏移，以及留一后是否明显漂移。
- 畸变系数的符号、量级及其在图像边缘造成的实际位移；联合 D 的校正图解释。
- 高误差图是否存在模糊、角点误检、棋盘弯曲或姿态不合适。
- 是否出现“训练误差很低，但留一内参变化很大”；低重投影误差不能单独证明参数准确。

### C 的运行与交接记录

在仓库根目录、安装 `requirements.txt` 所列依赖的隔离环境中运行。
首次生成模拟输入及评估图表：

```bash
PYTHONNOUSERSITE=1 python src/evaluate.py --demo
PYTHONNOUSERSITE=1 python experiments/exp_views.py \
  --corners outputs/demo/corners.json --output-dir outputs/demo
```

模拟使用固定种子 `20261110`、两台虚拟相机各 4 个视图、7×6 内角点、30 mm 间距，角点加入每坐标标准差 0.12 px 的高斯噪声。
模拟原图有醒目的来源标记；生成设置及真实模拟参数存于 `outputs/demo/demo_metadata.json`。
为保护已有输入，`--demo` 不覆盖已有 `corners.json/calib.json`。重跑已有模拟输入使用：

```bash
PYTHONNOUSERSITE=1 python src/evaluate.py \
  --corners outputs/demo/corners.json --calib outputs/demo/calib.json \
  --output-dir outputs/demo
```

A/B 合并后，用真实输入运行既有入口：

```bash
PYTHONNOUSERSITE=1 python src/evaluate.py
PYTHONNOUSERSITE=1 python experiments/exp_views.py
```

留一实验当前默认 `flags=0`、最大迭代 100 次、精度阈值 `1e-9`；与 B 对齐后可用 `--flags`、`--max-iter`、`--epsilon` 指定。
`--flags` 支持标准五参数畸变模型下 `FIX_K1/K2/K3` 和 `ZERO_TANGENT_DIST` 的组合。
