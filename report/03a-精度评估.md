### 3.1.3 重投影误差及独立复算

将第 $i$ 张图中第 $j$ 个棋盘格点 $M_j$ 按 B 的 $K,d,R_i,t_i$ 投影为 $\hat m_{ij}$，与 A 检测到的 $m_{ij}$ 比较：

$$
\mathrm{RMS}_i=\sqrt{\frac{1}{n_i}\sum_{j=1}^{n_i}
\left\|m_{ij}-\hat m_{ij}\right\|_2^2},\qquad
\mathrm{RMS}_{\mathrm{all}}=\sqrt{
\frac{\sum_i n_i\mathrm{RMS}_i^2}{\sum_i n_i}}.
$$

单位为像素。这是每点二维距离的均方根，不能将 $\|\mathrm{residual}\|_2/n_i$ 当作 RMS，也不能直接对各图 RMS 取算术平均。
C 与 B 均用 float32 的物体点和检测点进行投影，以 float64 累加残差。

| 相机 | 图像数 | C 重算整体 RMS (px) | 与 B 整体 RMS 的绝对差 (px) |
|---|---:|---:|---:|
| left | 4 | 0.096984981 | 0.000001007 |
| right | 4 | 0.119220120 | 0.000001334 |
| camA | 3 | 0.796436013 | 0.000001367 |
| camB | 3 | 0.910599978 | 0.000000547 |

14 张图的逐图 RMS 与 B 的 `per_image.rms` 完全一致；整体复算与 OpenCV 求解器报告值的差不超过 $1.4\times10^{-6}$ px，符合投影输出和求解器内部累加的数值精度差异。
这说明参数、图像和误差计算口径已对齐，属于训练重投影一致性验证。

### 3.1.4 留一法与焦距稳定性

每折仅用其余 $N-1$ 张图重新标定内参和畸变；随后固定该折的 $K,d$，用留出图角点通过 `solvePnP` 拟合该图外参，再计算留出图 RMS。
因此该误差是**拟合姿态后的留出视图重投影误差**，不能视为有已知独立姿态的测量精度。

每台相机另用完整图集在 C 当前环境重算一次，作为同环境数值对照。图中焦距变化均相对这次全量解计算，CSV 另列相对 B 正式解的变化，避免把环境或重复求解差异误归因于删图。
flags、迭代上限、阈值和 OpenCV 线程数均从 B 审计读取；实际配置为 128、2000、$10^{-10}$、8 线程。
C 与 B 的 Python 3.11.5、NumPy 2.4.6、OpenCV 5.0.0 版本一致，但 OpenCV 构建指纹不同，指纹均记录在实验审计中。

| 相机 | 训练图/留出图 | 完成折数 | 留出 RMS 范围 (px) | $f_x$ 范围 (px) | 相对同环境全量解的最大焦距变化 |
|---|---|---:|---:|---:|---:|
| left | 3 / 1 | 4/4 | 0.112966～0.150447 | 72.125～1559.770 | 499.30% |
| right | 3 / 1 | 4/4 | 0.118688～0.264083 | 77.245～111.655 | 35.00% |
| camA | 留一后仅 2 张 | 0，跳过 3 折 | 未生成 | 未生成 | 未生成 |
| camB | 留一后仅 2 张 | 0，跳过 3 折 | 未生成 | 未生成 | 未生成 |

![板 2 留一重投影误差与相对同环境全量解的焦距变化](outputs/experiments/views_board2.png)

左相机留出 `Im_L_3.png` 时，$f_x$ 从同环境全量约 260.820 px 变化至 1559.770 px，$f_y$ 相对变化达到 499.30%；对应留出 RMS 仍仅为 0.116310 px。
右相机留出 `Im_R_4.png` 时，$f_x$ 变化约 35.00%，留出 RMS 为 0.264083 px。
这表明即便重投影误差较低，现有板 2 图像仍不足以稳定确定内参，支持 B 已记录的数据约束不足结论。

同环境全量对照还发现：right 的 $f_x$ 为 82.706375 px，B 正式值为 78.295365 px，相差约 5.63%，两者整体 RMS 只差 $4.70\times10^{-7}$ px。
该结果独立记录，不覆盖 B 正式参数，也不声称已查明具体底层数值原因。不能将针孔公式代入这些不稳定焦距得到的视场角当成真实相机视场角。

板 1 两台相机各有 3 张采用图像。本实现的保守验收规则要求每折至少 3 张训练图，因此共 6 折明确记录为 `insufficient_views`，验证误差留空，不填零。
这是本次实验的最小训练视图策略，不代表任何约束条件下 OpenCV 都无法对两张图返回数值。
板 1 的全量训练复算正常，但缺少本方案下的留一验证，不能宣称已证明泛化精度。

### 3.1.5 参数合理性与结论

四个相机组中 $f_x,f_y$ 相差均在约 1.4% 以内，主点与图像中心的偏移约为 9～33 px，表面上没有明显尺寸或轴方向错误。
然而这类检查只能排除部分异常，无法单独证明内参可辨识。
畸变参数须与归一化坐标范围、重投影和 D 的去畸变结果联合分析，不能只因系数数值小就判定整幅图像校正可靠。

板 1 的整体训练误差约 0.80～0.91 px，高于板 2，但两块板对应的相机组、视图与成像条件不同，不能据此断言某块板本身更好。
需要结合角点质量、板的平面度及姿态覆盖分析；现有结果不能确定误差来源，也不能套用统一阈值后直接判为准确测量模型。

本次可确认：14 张图的训练重投影与 B 一致；板 2 的内参对视图选择明显敏感；板 1 只有少量同分辨率视图且缺少本方案的留一验证。
因此目前不能以这些结果保证独立三维测量精度。建议补拍不同倾斜方向、距离及图像边缘覆盖的视图，并保留额外图像或独立尺寸作为验证。

```bash
PYTHONNOUSERSITE=1 python src/evaluate.py --all
PYTHONNOUSERSITE=1 python experiments/exp_views.py
PYTHONNOUSERSITE=1 python experiments/exp_views.py \
  --corners outputs/corners_board1.json --calib outputs/calib_board1.json
```

单板入口仍兼容原流程：`python src/evaluate.py` 评估板 2；`--calib/--corners` 可指定单板输入。
`--all` 合并两块板的 14 行 CSV；独立单板运行会按约定更新该板的汇总表，交付时使用 `--all`。
留一实验不重新发布 B 的正式 JSON；正式配置与审计不符时拒绝运行。视图不足作为已记录跳过，求解失败则返回非零并保留已完成折。
