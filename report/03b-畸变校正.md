## 3.2 畸变校正与标定板对比

### 3.2.1 校正模型与实现

镜头畸变使理想针孔模型中的归一化坐标 $(x,y)$ 偏移。令 $r^2=x^2+y^2$，本实验采用 OpenCV 的五参数模型：

$$
\begin{aligned}
x_d &= x(1+k_1r^2+k_2r^4+k_3r^6)+2p_1xy+p_2(r^2+2x^2),\\
y_d &= y(1+k_1r^2+k_2r^4+k_3r^6)+p_1(r^2+2y^2)+2p_2xy.
\end{aligned}
$$

其中，$k_1,k_2,k_3$ 描述由镜片曲率引起的径向畸变，$p_1,p_2$ 描述镜片与成像平面不完全平行造成的切向畸变。B 的正式设置固定 $k_3=0$，保留 $k_1,k_2,p_1,p_2$。D 不重新估计这些参数，而是对每个相机组分别读取其 $K$ 和畸变系数，利用 `getOptimalNewCameraMatrix` 计算新内参，再通过 `initUndistortRectifyMap` 和 `remap` 进行反向映射。反向映射为校正图中的每个像素寻找原图采样位置，避免正向投影产生空洞。

`alpha` 控制有效像素与视野范围的权衡。`alpha=0` 通过缩放和裁剪尽量保证输出像素有效；`alpha=1` 尽量保留原图视野，但可能产生黑边；`alpha=0.5` 位于两者之间。本实验对每张图均生成 $0,0.5,1$ 三组结果，同时记录新内参、有效 ROI、映射有效率和像素位移。逐图检查发现 camB 在较大 alpha 下发生严重边缘外推，因此最终保存的主校正图统一采用 `alpha=0`，三种 alpha 的四宫格仍作为参数敏感性和失败模式证据保留。

输入图像严格来自 B 的 `per_image.file`，且只允许与对应 `camera` 和 `image_size` 的参数配对。实际处理 board2 的 left/right 各 4 张、board1 的 camA/camB 各 3 张，共 14 张。camA 的 `1.jpg` 分辨率为 3456×4608，与该组标定采用的 1080×1440 不同，因而未被缩放或校正；left/right 也只作为两个独立单目相机组处理，不进行双目外参推断。

### 3.2.2 校正结果与 alpha 选择

`alpha=0` 时四个相机组的 ROI 均覆盖约 99.7% 以上画面，14 张输出中没有大面积黑边。下图展示 camA 的代表结果。绿色线段由 Hough 变换标出少量长边，黄色虚线是相同像素位置的参考网格，两者用来辅助观察天花板格线、栏杆和标定板边框；它们不是独立的直线度误差测量。校正后这些结构边缘保持连续，画面边缘发生小幅重映射，没有出现不合理拉伸。

![board1/camA 的校正前后对比；主结果采用 alpha=0](outputs/figures/undistort_camA_2_compare.png)

board2 的畸变系数较小，校正前后肉眼差异有限。其板框和墙面交界仍保持连续，说明程序完成了数值映射，但不能仅凭“变化较小”判断内参可靠。B/C 已证明 board2 的焦距对迭代和视图选择敏感，因此这些图只能作为暂定模型下的效果探索。

![board2/left 的校正前后对比；主结果采用 alpha=0](outputs/figures/undistort_left_Im_L_1_compare.png)

### 3.2.4 问题、局限与结论

本节发现的首要问题是视图不足。board1 的 camA/camB 均只有 3 张同分辨率图像，低于工程标定常用的 10～20 张；board2 虽各有 4 张，但姿态和距离变化有限。`18.jpg` 检测成功、分辨率匹配并被正式标定采用，逐图 RMS 为 0.947834 px，不能简单判为不可用，但它也未提供独立验证。camA 的 `1.jpg` 因分辨率不匹配被排除，避免了未经证明的坐标和内参缩放。

第二个问题是整幅画面的外推质量未被训练 RMS 约束。棋盘主要覆盖图像中部，边缘缺少角点；camB 在 `alpha=0.5/1` 下的失稳正说明边缘校正不能由中部拟合误差保证。纸质或手持标定板的轻微翘曲也会违反平面假设，并与镜头畸变参数耦合。后续应增加不同距离、俯仰/偏航方向和靠近四角的 10～20 张视图，并保留额外图像或已知直线作为独立验证。

综上，D 已完成四个相机组的去畸变流程和 14 张图像的可视化输出。`alpha=0` 可生成无大面积无效区域的主结果；在各自暂定参数下，camA 与 board2 的 alpha 扫描未出现 camB 式的大面积无效区域，而 camB 的大 alpha 结果揭示了明显外推风险。现有结果足以验证程序链路和展示畸变校正方法，但不足以保证整幅图像校正精度或实际三维测量精度。

### 3.2.5 复现方式

在仓库根目录执行：

```bash
python src/undistort.py --calib outputs/calib.json
python src/undistort.py --calib outputs/calib_board1.json
python experiments/exp_boards.py
```

主校正图保存在 `outputs/undistorted/<camera>/`，前后对比和 alpha 对比位于 `outputs/figures/`。每个相机/alpha 的新内参、ROI、有效映射比例和位移统计记录在 `outputs/undistorted/undistort_<board>_summary.json`；板间完整数值与逐图统计分别记录在 `outputs/experiments/boards_compare.csv` 和 `boards_compare.audit.json`。
