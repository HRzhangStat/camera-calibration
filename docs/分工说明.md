### A —— 数据与角点检测

**负责**

1. **【第一天必须完成】确认标定板1 的内角点数**
   自动检测结果不一致（9×6 最多，另出现 10×8、7×6），说明检测到的是子网格。
   人工数一遍，把 `data/manifest.json` 里 `board1.pattern` 的 `null` 改成 `[列数, 行数]`。

2. 实现 `src/detect_corners.py` 的 `detect_one()`：
   - `cv2.findChessboardCornersSB(img, pattern, flags=CALIB_CB_EXHAUSTIVE | CALIB_CB_ACCURACY)`
   - 可选：`cv2.cornerSubPix()` 做亚像素精化
   - **输出顺序必须是行优先**（先第一行从左到右，再第二行）

3. 跑通全部 15 张图，统计成功率，记录失败原因

4. 生成角点可视化图 → `outputs/figures/corners_*.png`

5. **写对比实验** `experiments/exp_detector.py`：传统检测器 vs SB vs SB+亚像素，比较成功率和角点稳定性

**交付物**

- [ ] `data/manifest.json` 的 `pattern` 字段已填
- [ ] `src/detect_corners.py` 可运行
- [ ] `outputs/corners.json` 格式符合 README 约定
- [ ] `outputs/figures/corners_*.png`
- [ ] `outputs/experiments/detector_*.csv` 与对比图

**完成标准**

- 标定板2 的 8 张全部检测成功（7×6）
- 标定板1 至少 6/7 张成功，失败的在报告里说明原因
- `corners.json` 能被 B 直接读取，无需追问

**讲什么**：为什么用棋盘格、SB 算法与传统方法区别、亚像素为什么要做、失败案例。

**卡谁**：**卡 B**。第一天先交一个"能跑但粗糙"的版本，让 B 能开工。

### B —— 标定算法

**负责**

1. 实现 `src/calibrate.py`：
   - 二维点来自 `outputs/corners.json`
   - 生成三维点：7×6 网格，间距 30mm（或 50mm），Z=0
   - `cv2.calibrateCamera(objpoints, imgpoints, image_size, None, None)`
   - 用 `cv2.projectPoints()` 反算每张图的重投影误差，填进 `per_image`

2. **参数实验**：至少对比三组设置，选最合理的一组
   - 默认
   - `cv2.CALIB_FIX_K3`（只解 k1 k2）
   - `cv2.CALIB_ZERO_TANGENT_DIST`

3. **参数合理性检查**：$f_x \approx f_y$、主点接近图像中心、畸变系数量级正常

4. **写对比实验** `experiments/exp_flags.py`：四组 flags 组合的结果对比

**交付物**

- [ ] `src/calibrate.py` 可运行
- [ ] `outputs/calib.json`（含 K、dist、rms、per_image）
- [ ] `outputs/experiments/flags_*.csv` + md 表
- [ ] flags 对比表（交给 E 写进报告）

**完成标准**

- 每台相机都有完整参数
- RMS < 0.5 px（达不到要能解释原因）
- 参数物理合理

**讲什么**：张正友两步法、`calibrateCamera` 内部对应哪几步、flags 怎么选。

**卡谁**：**卡 C 和 D**。C/D 可以先用假数据开发，不必等。

### C —— 精度评估

**负责**

1. 实现 `src/evaluate.py`：
   - 读 `calib.json` + `corners.json`
   - 逐图计算 RMS 重投影误差
   - 画逐图误差柱状图
   - 画重投影叠加图（检测点红圈、重投影点蓝十字）

2. 输出 `outputs/tables/eval_summary.csv`

3. 撰写 `report/03a-精度评估.md`：内参表、畸变表、误差图、**参数合理性分析**

4. **写对比实验** `experiments/exp_views.py`：留一法（用 N-1 张标定、留 1 张验证），回答"3~4 张图到底够不够"

**交付物**

- [ ] `outputs/figures/eval_<camera>_errors.png`
- [ ] `outputs/figures/eval_<camera>_reprojection.png`
- [ ] `outputs/tables/eval_summary.csv`
- [ ] `outputs/experiments/views_*.png`
- [ ] `report/03a-精度评估.md`

**完成标准**

- 每台相机都有图有表
- 报告中明确回答"标定结果可不可信"

**讲什么**：重投影误差定义、怎么判断好坏（<0.3 优秀 / <0.5 正常 / >1 异常）、为什么"误差小 ≠ 参数对"。

**并行技巧**：第一天就用假 `calib.json` 把画图流程写完，B 出数据后直接替换。
